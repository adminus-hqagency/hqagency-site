# Owner checklist

Things the site needs from you before it's ready for clients. Nothing here was made up; these are blanks.

- [ ] **Contact email** → `js/config.js` `business.email` (shows in the footer, call-to-action bands and on Contact)
- [x] **Contact form** → connected to Formspree. Send yourself a test message from the live Contact page and confirm it arrives (the first one may ask you to confirm the form in Formspree).
- [ ] **Location / service area** (optional) → `business.city`, `state`, `region`
- [ ] **Phone and Instagram** (optional) → `business.phoneDisplay`/`phoneHref`, `instagramUrl`/`instagramHandle`
- [ ] **Logo**: the "HQ" tile with the orange corner is a placeholder made from type. Swap it if you have a real logo.
- [ ] **Turn on GitHub Pages** (Settings → Pages → `main` / root), and add a custom domain if you have one.
- [ ] **Sharing image**: add a 1200×630 `og-image.jpg` and an `og:image` tag once there's a domain.
- [ ] **Lacrosse photos**: the Basalt Lacrosse concept uses real game photos. Confirm the players and families are fine with that, or swap them (open question carried over from the vault).
- [ ] **Real client work**: when you finish a paid project, add it to the top of the `work` list in `js/config.js` with a screenshot in `assets/work/`.
