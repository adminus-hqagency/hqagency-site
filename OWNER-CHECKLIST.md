# Owner checklist

Things the site needs from you before it's ready for clients. Nothing here was made up; these are blanks.

- [ ] **Contact email** → `js/config.js` `business.email` (shows on Contact and in the footer)
- [ ] **Form endpoint** → make a Formspree form and paste the URL in `js/config.js` `contactForm.endpoint`. Until then, the form does not send messages.
- [ ] **Location / service area** (optional) → `business.location`
- [ ] **Phone and Instagram** (optional) → `business.phone`, `business.instagram`
- [ ] **Logo**: the "HQ" mark is a placeholder made from type. Swap it if you have a real logo.
- [ ] **Turn on GitHub Pages** (Settings → Pages → `main` / root), and add a custom domain if you have one.
- [ ] **Sharing image**: add a 1200×630 `og-image.jpg` and an `og:image` tag once there's a domain.
- [ ] **Lacrosse photos**: the Basalt Lacrosse concept uses real game photos. Confirm the players and families are fine with that, or swap them (open question carried over from the vault).
- [ ] **Real client work**: when you finish a paid project, add it above the concepts on `work.html`.
